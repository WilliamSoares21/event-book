# Infraestrutura

Este diretório concentra arquivos relacionados à execução e à infraestrutura do EventBook, como configurações de containers, ambientes e deploy.

O `docker-compose.yml` atualmente na raiz continua sendo o ponto de entrada para a composição local. Novos arquivos de infraestrutura devem ser organizados aqui quando deixarem de ser compartilhados pela raiz.

Sobre o EventBook

O EventBook é uma aplicação de gerenciamento e bilheteria de eventos desenvolvida como projeto prático no curso Full Cycle do programa Geração Tech 4.0, uma iniciativa impulsionada pelo IEL.

Nossa Proposta

Facilitar o ecossistema de eventos conectando organizadores e participantes de forma transparente e segura, utilizando tecnologias modernas de mercado tanto no frontend quanto no backend.

Arquitetura e Tecnologia

Frontend: Angular 22 com Signals e Bootstrap.

Backend: Java 21, Spring Boot 4.1.1 e PostgreSQL.

Infraestrutura: Docker, Docker Compose, CI/CD e Cloudflare R2.
